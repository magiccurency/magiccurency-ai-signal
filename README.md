# MAGICCURENCY AI SIGNAL

MAGICCURENCY AI SIGNAL is an AI-powered XAUUSD signal system built using Smart Money Concept (SMC), MetaTrader 5, FastAPI, and WhatsApp automation.

The goal of this project is to generate high-quality trading signals by combining institutional trading concepts with automated analysis and real-time notifications.

---

## Features

- Smart Money Concept (SMC)
- Market Structure Shift (MSS)
- Break of Structure (BOS)
- Change of Character (CHoCH)
- Order Block Detection
- Fair Value Gap (FVG)
- Liquidity Sweep Detection
- Premium & Discount Zones
- Multi-Timeframe Analysis
- AI Confidence Score
- News Filter (FOMC, NFP, CPI)
- Risk/Reward Calculation
- Automatic Stop Loss & Take Profit
- MT5 Integration
- FastAPI Backend
- WhatsApp Signal Automation
- Live Dashboard
- Signal History
- Win Rate Statistics
- PostgreSQL Database
